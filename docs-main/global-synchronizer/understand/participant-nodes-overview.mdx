---
title: "Participant Nodes overview"
description: "What a Canton participant node does and what you manage as its operator"
---

A participant node is the Canton node that hosts parties and stores the contracts they are stakeholders in. It validates and confirms transactions for the parties it hosts, and connects to one or more synchronizers to exchange messages with other participant nodes. Applications reach it through the Ledger API. Operators reach it through the Admin API and the Canton Console.

Every validator and Super Validator node includes a participant node. The Splice Validators and Splice Super Validators sections cover the Splice components that run alongside it. This section covers the participant node itself: its configuration and identity, the parties and packages it hosts, its users and keys, and its data.
