<ResponseField name="availability" type="VotesAvailability" required>

Whether this Scan holds all vote results before the requested record time. &quot;available&quot;: it does. &quot;ingesting&quot;: not yet. Its vote results are fully backfilled, but its own ingestion has not reached the requested record time yet; it will answer &quot;available&quot; once it has. &quot;backfilling&quot;: its own vote results are not fully backfilled yet, so it does not know whether earlier vote results exist, and must not be used as a source for backfilling.


Allowed values: <code>available</code>, <code>ingesting</code>, <code>backfilling</code>.





</ResponseField>
