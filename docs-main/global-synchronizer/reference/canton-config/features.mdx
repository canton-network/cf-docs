## All options

### `canton.features`

<Tabs>
<Tab title="HOCON">

```hocon
canton.features {
  enable-preview-commands = false

}
```

</Tab>
<Tab title="Table">

| Key | Type | Default | Description |
|---|---|---|---|
| `enable-preview-commands` | boolean | `false` (in practice `true`) ◊ | Feature flag to enable the set of commands that use functionality which we don't deem stable. |
| `enable-repair-commands` | boolean | `false` (in practice `true`) ◊ | Feature flag to enable the set of commands used by Canton operators for manual repair purposes. |
| `enable-testing-commands` | boolean | `false` (in practice `true`) ◊ | Feature flag to enable the set of commands used by Canton developers for testing purposes. |
