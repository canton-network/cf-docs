<ParamField body="before_record_time" type="string" required>
OpenAPI type: <code>string (date-time)</code>.



Only return vote results with a record time strictly smaller than this time, or with this record time and an event number strictly smaller than `before_event_number`.






</ParamField>



<ParamField body="before_event_number" type="number" required>
OpenAPI type: <code>integer (int32)</code>.








</ParamField>



<ParamField body="count" type="number" required>
OpenAPI type: <code>integer (int32)</code>.



Return at most this many vote results. The actual number returned may be smaller.



Minimum: 1; Maximum: 1000.




</ParamField>
