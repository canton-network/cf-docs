## Inputs



### Request body


<div class="x2mdx-ref-badges">

  <span class="x2mdx-ref-badge x2mdx-ref-badge--neutral">application/json</span>

</div>






<ParamField body="actionName" type="string" />



<ParamField body="accepted" type="boolean" />



<ParamField body="requester" type="string" />



<ParamField body="effectiveFrom" type="string" />



<ParamField body="effectiveTo" type="string" />



<ParamField body="limit" type="number" required>
OpenAPI type: `integer`.



</ParamField>



<ParamField body="pageToken" type="number">
OpenAPI type: `integer`.


Cursor for pagination. When requesting the next page of results, pass the `next_page_token` from the previous response. Results are ordered by effective date (the accepted vote&#x27;s effectiveAt, or the result&#x27;s completedAt otherwise), descending.
</ParamField>









## Outputs



### 200


<div class="x2mdx-ref-badges">

  <span class="x2mdx-ref-badge x2mdx-ref-badge--neutral">application/json</span>

</div>






<ResponseField name="dso_rules_vote_results" type="object[]" required />



<ResponseField name="next_page_token" type="integer">
Cursor for the next page of results. Pass this as `pageToken` in the request. If absent or `null`, there are no more pages.
</ResponseField>
