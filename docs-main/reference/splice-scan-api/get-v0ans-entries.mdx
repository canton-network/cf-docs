## Inputs



### Query parameters







<ParamField query="name_prefix" type="string">

Every result&#x27;s name will start with this substring; if empty or absent, all entries will be listed. Does not have to be a whole word or segment; any substring will be accepted.
</ParamField>



<ParamField query="page_size" type="number" required>
OpenAPI type: `integer (int32)`.


The maximum number of results returned. Older (but still non-expired) results are listed first.
</ParamField>
