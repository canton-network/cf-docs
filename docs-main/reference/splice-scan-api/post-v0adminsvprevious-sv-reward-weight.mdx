## Inputs



### Request body


<div class="x2mdx-ref-badges">

  <span class="x2mdx-ref-badge x2mdx-ref-badge--neutral">application/json</span>

</div>






<ParamField body="svParty" type="string" required />



<ParamField body="effectiveBefore" type="string">

Only consider reward weight changes that took effect strictly before this time.
</ParamField>









## Outputs



### 200


<div class="x2mdx-ref-badges">

  <span class="x2mdx-ref-badge x2mdx-ref-badge--neutral">application/json</span>

</div>






<ResponseField name="rewardWeight" type="string">
The SV&#x27;s reward weight set by the most recent accepted `UpdateSvRewardWeight` proposal before `effectiveBefore`, or absent if there is no such proposal.
</ResponseField>
