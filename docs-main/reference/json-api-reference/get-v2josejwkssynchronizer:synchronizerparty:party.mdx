## Authorizations


### httpAuth






<ParamField header="Authorization" type="string" required>


HTTP bearer authentication. Send the token as `Authorization: Bearer &lt;token&gt;`. Ledger API standard JWT token






</ParamField>






### apiKeyAuth






<ParamField header="Sec-WebSocket-Protocol" type="string" required>


API key authentication in the header. Ledger API standard JWT token (websocket)






</ParamField>








## Path parameters








<ParamField path="synchronizer" type="string" required>


synchronizer from which to read the public keys






</ParamField>



<ParamField path="party" type="string" required>


party for which to retrieve the public keys






</ParamField>
