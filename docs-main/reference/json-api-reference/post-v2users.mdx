OpenAPI type: `User`.


Users and rights ///////////////// Users are used to dynamically manage the rights given to Daml applications. They are stored and managed per participant node.
</ParamField>



<ParamField body="rights" type="object[]">
OpenAPI type: `Right[]`.


The rights to be assigned to the user upon creation, which SHOULD include appropriate rights for the ``user.primary_party``. Optional: can be empty
</ParamField>
