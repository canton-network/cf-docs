## Inputs



### Path parameters







<ParamField path="domain_id" type="string" required>

The synchronizer ID to look up a mapping for.
</ParamField>



<ParamField path="party_id" type="string" required>

The party ID to lookup a participant ID for.
</ParamField>









## Outputs



### 200


<div class="x2mdx-ref-badges">

  <span class="x2mdx-ref-badge x2mdx-ref-badge--neutral">application/json</span>

</div>






<ResponseField name="participant_ids" type="string[]" required>
IDs of the participants hosting the provided party, each in the form `PAR::id::fingerprint`
