  <p class="x2mdx-ref-summary">Retrieve created event blobs for active contracts of the Daml template `Splice.Amulet:RewardCouponV2` by contract ID. Requests are limited to 100 contract IDs; larger requests return 400. Missing or archived contracts, and contracts of other templates, are omitted from the response. If no matching active contracts are found, the response contains an empty map.</p>
