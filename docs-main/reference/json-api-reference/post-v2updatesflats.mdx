<p><strong>Removed in 3.7.</strong> Historical definition from 3.6.</p>

Query flat transactions update list (blocking call). Notice: This endpoint should be used for small results set. When number of results exceeded node configuration limit (`http-list-max-elements-limit`) there will be an error (`413 Content Too Large`) returned. Increasing this limit may lead to performance issues and high memory consumption. Consider using websockets (asyncapi) for better efficiency with larger results.
