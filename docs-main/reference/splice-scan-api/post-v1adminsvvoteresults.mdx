## Body



<div class="x2mdx-ref-badges">

  <span class="x2mdx-ref-badge x2mdx-ref-badge--neutral">application/json</span>

</div>






<ParamField body="filters" type="object">
OpenAPI type: <code>VoteResultsFiltersV1</code>.



**EXPERIMENTAL**: subject to change. Filters for vote results. A vote result is returned if it matches all filters that are set.





<Expandable title="child attributes">




<ParamField body="action_name" type="string">


Only return vote results whose action name contains this string, e.g., `SRARC_AddSv`.






</ParamField>



<ParamField body="accepted" type="boolean">


Only return vote results that were accepted (`true`), or that were rejected or expired (`false`).






</ParamField>



<ParamField body="requester" type="string">


Only return vote results whose requester name contains this string.






</ParamField>



<ParamField body="effective_from" type="string">
OpenAPI type: <code>string (date-time)</code>.



Only return vote results whose effectiveAt is at or after this time. Vote results without an effectiveAt (rejected or expired ones) never match.






</ParamField>



<ParamField body="effective_to" type="string">
OpenAPI type: <code>string (date-time)</code>.



Only return vote results whose effectiveAt is at or before this time. Vote results without an effectiveAt (rejected or expired ones) never match.






</ParamField>




</Expandable>


</ParamField>



<ParamField body="page_size" type="number" required>
OpenAPI type: <code>integer (int32)</code>.



The maximum number of vote results returned for this request.



Minimum: 1; Maximum: 1000.




</ParamField>



<ParamField body="page_token" type="string">


Cursor for pagination. To request the next page of results, pass the `next_page_token` of the previous response, together with the same filters. The cursor is opaque.






</ParamField>







## Responses


### 200

ok



<div class="x2mdx-ref-badges">

  <span class="x2mdx-ref-badge x2mdx-ref-badge--neutral">application/json</span>

</div>






<ResponseField name="vote_results" type="VoteResultV1[]" required>





<Expandable title="child attributes">




<ResponseField name="record_time" type="string (date-time)" required>

The record time of the transaction in which the vote request was closed.






</ResponseField>



<ResponseField name="synchronizer_id" type="string" required>

The synchronizer of the transaction in which the vote request was closed.






</ResponseField>



<ResponseField name="update_id" type="string" required>

The update id of the transaction in which the vote request was closed.






</ResponseField>



<ResponseField name="event_number" type="integer (int32)" required>

The number of the `DsoRules_CloseVoteRequest` exercise event within the transaction. Identical across Scans: events are numbered by traversing the transaction in order.






</ResponseField>



<ResponseField name="dso_rules_contract_id" type="string" required>

The contract id of the DsoRules on which the `DsoRules_CloseVoteRequest` choice was exercised, i.e., of the DsoRules at the time the vote request was closed.






</ResponseField>



<ResponseField name="vote_result" type="object" required>

The `DsoRules_CloseVoteRequestResult` of the choice, in the compact Daml JSON encoding. Optional fields without a value may be encoded as `null` or omitted.






</ResponseField>



<ResponseField name="dso_rules" type="object">

**EXPERIMENTAL**: not populated yet, and its format may change. The payload of the DsoRules with contract id `dso_rules_contract_id`, e.g., for mapping the SV names in the vote result to SV party ids.






</ResponseField>




</Expandable>


</ResponseField>



<ResponseField name="next_page_token" type="string">

Cursor for the next page of results. Pass this as `page_token` in the next request. Absent if this page is empty, which means that there are no more pages. A page that is not empty always has a cursor, even if it is the last one.






</ResponseField>
